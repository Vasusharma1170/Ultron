Project Ultron is currently making two products: Omni-AI and the Ultron robot. 
Omni-AI is a neural network-based AI which contains the majority of specialised modules for upgrading the efficiency and accuracy for human activities.
Omni-AI will be using a highly restricted sandbox and an advanced AI precept to ensure maximum human safety possible.
Omni-AI will also be used to operate the Ultron robot.
The Ultron Robot itself will have 3 stages for completion.
Stage 01 includes facial recognition and equipment usage for the robotic arm.
Stage 02 will introduce the entire torso model for the Ultron robot.
Stage 03 will have a completely functional Ultron robot for commercial/government use.
